# Packman

A small, self-contained Pac-Man-style maze game that runs in any modern browser.

## Play

Open `index.html` directly in your browser, or serve the project folder locally:

```sh
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

Use the **arrow keys** or **WASD** to move through the maze. Collect every dot
and power pellet while avoiding the ghosts. Power pellets let you catch ghosts
for a short time. You have three lives; the game ends when they run out. Select
**New game** at any time to restart.
